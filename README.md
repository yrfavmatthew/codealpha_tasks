# Learnly

*UI/UX Design Submission — CodeAlpha Internship (Tasks 1 & 2)*

## Project Overview

Learnly is a mobile-first online learning platform that helps self-directed learners discover, complete, and retain skill-based courses. It combines the structured course catalog experience of platforms like Coursera with a restrained, professional layer of motivational mechanics inspired by Duolingo — without the cartoonish, high-energy visual language.

*Vision: "Make consistent learning feel achievable and visible, without turning education into a game."*

## Problem Statement

Research into two established learning platforms — Coursera and Khan Academy — surfaced recurring UX failures that Learnly is designed to solve:

- Coursera: navigation confusion, lost progress orientation, perceived performance issues
- Khan Academy: unclear onboarding, cognitive overload, no personalization

## Design System Summary

**Color:**
- Primary: muted, confident blue (`#2C5EAA`)
- Neutral background: off-white / light gray (`#F7F9FC`)
- Accent: single warm tone reserved exclusively for streaks/badges

**Typography:**
- One typeface family, two weights (e.g. Inter or Manrope)
- Scale: H1 / H2 / Body / Caption — no more than 4 sizes

**Components:**
- Reusable course card, primary/secondary button, input field (default/focus/error), progress ring, badge chip
- 8pt spacing grid throughout
- Consistent corner radius and elevation across all cards and modals

## Gamification Approach

Gamification is used only where it reinforces a real learning behavior — returning daily, finishing a module, retaining a concept. Never used purely for novelty.

- **Streaks:** numeric counter, not animated
- **Badges:** flat, icon-based milestones shown quietly on profile
- **Progress ring:** subtle circular indicator on course cards
- **Certificates:** clean, single-color design suitable for LinkedIn sharing

*Explicitly excluded: mascots, confetti, sound effects, leaderboards, aggressive streak-loss guilt notifications.*
